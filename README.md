# 🎓 Seemanta Campus — Job Board

A simple, responsive job and internship board built for students and campus recruiters. It lets students search and filter live openings, and lets recruiters or the placement cell post a new opening directly — no backend or database required, everything runs and persists right in the browser.

## 🌐 Live Demo

Check out the live demo of Seemanta Campus [here](https://seemanta-campus.vercel.app/).

## 🚀 Features

* Searchable board of internship and full-time openings.
* Filter chips to instantly narrow results by employment type.
* "Post an opening" form for recruiters — new listings appear on the board immediately.
* Listings are saved with `localStorage`, so posted openings persist across page reloads.
* Simple, responsive design that works on both desktop and mobile devices, with a collapsible mobile menu.
* Displays company, location, pay/stipend, and application deadline for every listing.

## 🛠️ Tech Stack

* **HTML** : For the structure of the job board, listings, and post form.
* **CSS** : For styling, layout, and responsive breakpoints.
* **JavaScript** : For search, filtering, form handling, and data persistence via `localStorage`.

## 🧑‍💻 Getting Started

Follow the steps below to clone and use the project locally:

### 1. Prerequisites

Make sure you have Git installed. If not, you can download it [here](https://git-scm.com/).

### 2. Clone the Repository

```
git clone https://github.com/kritimansethy/Seemanta-Campus.git
```

### 3. Run the project

No build tools, API key, or server required — just open `index.html` directly in your browser.
